Transformers & LLMs

Nineteen sections, from what a Transformer is to how LLMs are trained, served and fine-tuned. Each section has lecture notes; most also have an exercise sheet with worked solutions and a runnable Python lab.

Read the sections in order: each one builds on the notation and examples of the ones before it. Labs run with uv run python <section>/lab.py from the project folder.

# Course log

Course-wide decisions and what each section has covered, so later sections stay consistent. Notation follows `.claude/skills/bachelor-notes/style-guide.md`.

## Conventions
- Block arrangement: **pre-norm** (`x + Sublayer(LN(x))`) is the default in diagrams and formulas; post-norm is mentioned as the 2017 original.
- Running intuition: the **classroom discussion** (tokens = students holding word cards; attention = everyone talking to everyone; FFN = each student thinking alone).
- Motivating sentence: *"Riya poured water into the glass until it was full."* ("it" → glass).
- Home page: `index.html` links every section's notes, exercises, solutions and lab. Labs run with `uv run python <section>/lab.py`; `pyproject.toml` sets uv's link-mode to copy, because OneDrive blocks hard links in `.venv`.
